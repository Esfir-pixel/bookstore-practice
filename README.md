# Книжный магазин
Web-приложение книжного магазина с покупкой и арендой книг, личным кабинетом и админ-панелью.
Построено на **Next.js 16 (App Router) + TypeScript + Supabase**.

## Функциональность
### Пользователь
- Каталог книг с сортировкой по категории, автору, году написания
- Покупка книги
- Аренда на 2 недели / 1 месяц / 3 месяца
- «Мои аренды» с таймером обратного отсчёта
- Возврат арендованной книги
- Уведомления об окончании аренды
- Профиль пользователя

### Администратор
- Дашборд со статистикой (книги, аренды, покупки, пользователи)
- CRUD книг: добавление, редактирование, удаление
- Управление ценами (покупка + три периода аренды)
- Управление статусами (доступна / скрыта / архив)
- Список всех аренд с фильтрами
- Ручные напоминания пользователям
- Управление пользователями: смена роли, удаление

### Автоматизация
- SQL-функция `mark_rentals_expired()` — создаёт уведомления за 3 дня до окончания аренды и автоматически истекает просроченные
- Vercel Cron — ежедневный запуск в 09:00 UTC

## Стек
 Технология 
 **Next.js 16** - App Router, Server Components, Server Actions 
 **TypeScript** - Типизация 
 **Supabase** - PostgreSQL, Auth, RLS, Storage 
 **shadcn/ui (Base UI)** - UI-компоненты 
 **Tailwind CSS 4** - Стилизация 
 **Vercel Cron** - Планировщик напоминаний 
 **lucide-react** - Иконки 
 **sonner** - Toast-уведомления
